Selected Labs & Assignments

These examples highlight hands-on exercises I developed for GIS and remote sensing instruction. Each lab combines conceptual explanation, guided workflows, spatial analysis, and applied mapping.

01
Land-Cover Classification & Change Detection
Remote Sensing ArcGIS Pro Random Forest Change Detection
⌄

Students create land-cover maps from multitemporal aerial imagery and analyze how the landscape changed between 2008 and 2023.

  • Collect and manage supervised training samples
  • Classify imagery using Random Forest
  • Create five land-cover classes
  • Perform from-to land-cover change detection
  • Identify dominant landscape transitions
  • Design a final thematic change map

02
Spectral Indices & Vegetation Mapping
Sentinel-2 NDVI NDWI Raster Analysis
⌄

Students explore multispectral imagery and use spectral indices to examine vegetation and surface water.

  • Create NDVI and NDWI from Sentinel-2 imagery
  • Interpret multispectral bands and false-color composites
  • Use Raster Calculator and threshold-based classification
  • Convert raster vegetation classes to vector features
  • Calculate vegetation area
  • Create publication-style map layouts
View Lab Instructions
03
Spatial Point Pattern Analysis
iNaturalist Kernel Density Thiessen Polygons Species Distribution
⌄

Students work with citizen-science species observations to study spatial concentrations and changes in species observation patterns over time.

  • Download and prepare iNaturalist occurrence data
  • Convert tabular coordinates into GIS point features
  • Project spatial data for analysis
  • Create Thiessen polygons
  • Estimate concentrations using Kernel Density
  • Compare species observation density between years
View Lab Instructions
04
Digitizing & Geospatial Data Creation
ArcGIS Pro Geodatabase Digitizing Cartography
⌄

Students build a geospatial data model of the University of Florida campus using point, line, and polygon feature classes.

  • Create and organize a file geodatabase
  • Design point, line, and polygon feature classes
  • Create and populate attribute fields
  • Digitize real-world campus features
  • Apply symbology and labels
  • Produce a final campus map layout
